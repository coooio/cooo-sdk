# cooo-lyquid

Authoritative synthetic Lyquid for the public cooo SDK local quickstart. It targets Lyquor LDK `0.8.0` and protocol identity `cooo-local-v0.3-terms-bound-review`.

This crate intentionally supports a local single-node evaluation environment. It does not provide real assets, custody, production signing, public deployment, or multi-node consensus. Build and deployment are handled by the officially installed Lyquor `shaker` tool through `devnet/start.sh`.
